# Heart Disease Prediction using Decision Tree

## 📌 Project Overview

This project aims to predict the presence of heart disease in patients using Machine Learning techniques, specifically the **Decision Tree Classifier**.

The dataset contains various medical attributes such as:

- Age
- Sex
- Chest Pain Type
- Blood Pressure
- Cholesterol Level
- Maximum Heart Rate
- ECG Results
- Oldpeak
- Thalach
- Other clinical parameters

The objective is to classify whether a patient is likely to have heart disease (`target = 1`) or not (`target = 0`).

Early prediction of heart disease can help healthcare professionals provide timely treatment and preventive care.

---

# 🎯 Problem Statement

Heart disease is one of the leading causes of death worldwide. Early diagnosis plays a crucial role in reducing health risks and improving patient outcomes.

The goal of this project is to build a Machine Learning classification model using a **Decision Tree** that can accurately predict the presence of heart disease based on patient medical data.

---

# ⚙️ Solution Approach

The following steps were performed to solve the problem:

## 1. Data Preprocessing

- Checked for missing values
- Verified data types of all features
- Encoded categorical variables where necessary
- Prepared clean dataset for modeling

---

## 2. Exploratory Data Analysis (EDA)

Performed data visualization and analysis using:

- Count plots
- Histograms
- Boxplots

Key observations:

- Certain chest pain types showed stronger correlation with heart disease
- Some features contained outliers
- Heart rate and oldpeak had noticeable impact on predictions

---

## 3. Feature Selection

Selected important medical attributes contributing to heart disease prediction.

Examples:

- Chest Pain Type (`cp`)
- Maximum Heart Rate (`thalach`)
- Oldpeak
- Cholesterol
- Blood Pressure

---

## 4. Model Building

Implemented **Decision Tree Classifier**.

Decision Trees work by splitting data into branches based on feature conditions to make classification decisions.

---

## 5. Model Evaluation

The model was evaluated using:

- Accuracy Score
- Confusion Matrix

The Decision Tree structure was also visualized for better understanding of prediction logic.

---

## 6. Interpretation

Analyzed the decision rules generated by the tree to understand how predictions were made.

Important features influencing predictions included:

- `cp`
- `thalach`
- `oldpeak`
